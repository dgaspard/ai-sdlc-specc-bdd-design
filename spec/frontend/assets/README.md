No stock photography or generated raster artwork is needed for this identity.

`fonts/inter-latin-400-normal.woff2` and `fonts/inter-latin-600-normal.woff2`
are copied unchanged from `@fontsource/inter` 5.3.0. License: OFL-1.1; see
`fonts/LICENSE` for the full copyright and license notice. Upstream distribution:
https://registry.npmjs.org/@fontsource/inter/-/inter-5.3.0.tgz

These files are served locally, retained across reconstruction, and covered by
the protected manifest after human review/freeze. Keep the license with any copy.
Changing a font file or logo is a design-contract change, not a routine build fix.
